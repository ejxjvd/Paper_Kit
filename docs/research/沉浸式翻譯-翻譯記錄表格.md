# 沉浸式翻譯 翻譯記錄頁（`/zh-TW/document/record/`）盤點

> 來源：使用者貼圖逐字轉錄（兩個 tab 狀態）＋桌機保存 HTML `翻譯記錄.html`（691KB）。
> 用途：Paper_Kit 任務歷史頁（票 08 已做）的對照標竿——表格化、批量操作、分頁是沉浸式翻譯的做法。

## 1. 頁面結構

```
沉浸式翻譯 > 翻譯記錄
翻譯記錄
├─ 頁頂：↪ 回到舊版本
├─ 分類切換：PDF Pro 按鈕 / BabelDOC 按鈕（tab 化，當前選取＝白色、其他＝灰色）
├─ 表格工具列：
│   ├─ ← 返回
│   ├─ 🗑 批量刪除（淡粉圖示按鈕）
│   ├─ ⤓ 批量下載僅譯文
│   └─ ⤓ 批量下載雙語
├─ 表格（第一欄＝圓形勾選框，表頭可全選）
└─ 分頁：上一頁 < / 頁碼 1（選取＝粉紅）/ 下一頁 >；每頁顯示 10 ˅ 條
```

## 4. 知識點

1. **狀態標籤**：`已逾期`（紅色）＝線上服務的檔案保留期限（對應 FAQ「過期時間」欄）——本機工具無此概念
2. **任務類型欄**：`單文件`——沉浸式翻譯有「批量翻譯」類型（Pro 限定）
3. **翻譯服務欄**：每筆記錄顯示所用引擎（`智譜 4 Flash`）——Paper_Kit 任務卡目前未顯示所用引擎，可補
4. **批量操作**：勾選＋批量刪除／批量下載僅譯文／批量下載雙語——Paper_Kit 目前逐卡操作，無批量
5. **分頁**：每頁 10 條、頁碼導覽——Paper_Kit 任務清單為捲動卡片，量大時無分頁
6. 沉浸式翻譯記錄頁**只有歷史**，無重試/取消（狀態終結）；Paper_Kit 有 `↻ 重試`/`✕ 取消`（任務卡）——Paper_Kit 勝出
