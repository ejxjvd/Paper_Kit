# 問題與解答：#82 刪除確認 dialog「不到 2 秒就消失」（第 3 次回報，已根治）

> 常駐問題解決包（重點 1：重複問題 ≥3 次 → 立即建立常駐方案）。機制由 diagnosing-bugs 回饋迴圈完整鎖定。

## 症狀

主頁任務卡點「🗑 刪除」→ 確認 dialog 顯示**不到 2 秒就消失**，使用者第 3 次回報（2026-08-13）。同機制還影響「瀏覽器內預覽」dialog（且 `ui.pdf` 在 NiceGUI 3.15 不存在，點擊靜默 AttributeError）。

## 診斷（Phase 1-4，假說檢驗）

| 階段 | 證據 | 結論 |
|---|---|---|
| 回饋迴圈 | `test_delete_dialog_survives_refresh_cycle`：點刪除 → dialog 開 → 2.5s → **dialog 消失（紅）** | 確定複現 |
| 時間線 | [DEBUG-82b] 觀察：dialog 活到 t=0.8s，死於 t=1.2s（第一次 1.0s timer fire） | 殺手＝1s 輪詢 `_refresh` |
| 掛載點 | dialog 本體掛 `layout`；canary 元素掛「handler 執行上下文」 | 指向 canary 機制 |
| 實驗 A | monkeypatch `_refresh` 為 no-clear 版 → **dialog 存活（綠）** | `cards.clear()` 是必要條件 |
| 實驗 B | monkeypatch 為 clear-only 版（暖身後切換）→ 存活 | clear 無辜，「clear＋canary 連坐」才是機制 |

## 根因（NiceGUI 框架層機制）

1. `events.handle_event` 在 **sender 的 parent slot** 上下文執行 handler（events.py:467-473）＝觸發按鈕所在**卡片 slot**。
2. `ui.dialog()` 建構（dialog.py:31-42）：dialog 本體掛 `context.client.layout`，但**不可見 canary 元素掛「當前上下文」**（卡片 slot），且 `weakref.finalize(canary, lambda: self.delete())` 連坐。
3. 每秒 `_refresh` → `cards.clear()` → `client.remove_elements(cards.descendants())` → 刪卡片（含 canary）→ finalize 觸發 → **dialog.delete()**。
4. 使用者 3 次回報的「2 秒內消失」＝第一次 timer fire 的時間窗，完全吻合。

## 修復（Phase 5）

**頁面級單例 dialog**（NiceGUI 官方建議 create once & reuse）：

- `_index_page` 中 `cards` 建置後建立：`delete_dialog`（含確認/取消，確認讀 `delete_state["job_id"]`）＋ `preview_dialog`（`preview_box = ui.html("")`）。canary 掛永存容器，不隨卡片死。
- `_confirm_delete_one(service, job_id, dialog, state)`：只 `state["job_id"] = job_id; dialog.open()`。
- `_preview(dialog, box, url)`：`box.set_content('<iframe src=...>')` ＋ `dialog.open()`（取代不存在的 `ui.pdf`）。
- `_render_card`／`_refresh`／timer lambda 傳入 4 參數（有預設值，向後相容）。

## 教訓（防止再犯）

- **NiceGUI 紅線：handler 內 `with ui.dialog()` 重建 + 外部 clear 容器 = 必死**。所有 dialog 一律頁面級單例。
- `should_see(kind=ui.dialog, content=...)` 永不匹配（Dialog 非 TextElement，content 只查元素自身屬性）——抓 dialog 用 `user.find(kind=ui.dialog)` ＋ `props["model-value"]`。
- 假說實驗的 monkeypatch 必須在「前置條件已就緒」後才套用（實驗 B setup 假陰性教訓）。
- `ui.pdf` 在 NiceGUI 3.15 不存在——預覽用 `ui.html` ＋ iframe。
