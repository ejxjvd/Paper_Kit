# #83 Chrome 下載 mono/dual 失敗（「失敗 - 沒有檔案」+ .htm）— 根因鏈與修復

日期：2026-08-13 ｜ 狀態：✅ 已根治 ｜ 相關：[[#82]]、[[2026-08-13-Paper_Kit-Daily-Note]]

## 問題（使用者回報）

Chrome 下 4 筆下載全失敗：訊息「失敗 - 沒有檔案」，檔名變成 `.htm`（原本應是 `.pdf`）。

## 根因鏈（三層，完整實測）

```
① build_command：deepseek provider + auto_extract
   → 無條件送 --term-siliconflow-api-key cfg.api_key（= deepseek key）
   → term 引擎＝SiliconFlow 收錯 key → 401「Token is invalid」(code 30014)
② pdf2zh_next 引擎：子進程失敗（401）時 rc=0 靜默吞掉
   → 零產出、log 無 MonoPDF/DualPDF 行（repro B 實證）
③ Paper_Kit parse_output：無 MonoPDF 行時靜默 fallback 慣例檔名 {stem}.zh.mono.pdf
   → 不驗證檔案存在 → ghost COMPLETED（job 67be2032：7s、tokens=0）
④ UI 下載：ui.download(缺檔路徑)
   → NiceGUI helpers.is_file=False → fallback from_url(path)
   → 瀏覽器 fetch 404、服務端回 HTML →「失敗 - 沒有檔案」+ .htm
```

**對照實驗**：repro A（term 用正確 SF key）→ rc=0 + 完整產出 + MonoPDF 行可解析；
repro B（app 實際組裝法，term 用 DS key）→ 401 + 零產出 + rc=0。兩者完全對照出
① 的 key 錯配。

## 引擎源碼實證（pdf2zh_next 2.9.0）

- `cli_env_model.py:107`：`term_extraction_engine_settings = None`——**沒有 `--term-*`
  旗標時 term 引擎整個不啟動**（不需 key、不呼叫、不上雲）。
- `high_level.py:100`：`get_term_translator` 在 settings 為 None 時回 None。
- 敏感紅線（票 10）：`sensitive_ok=True` 只有 deepseek——舊行為等於**機密內容送
  SiliconFlow 雲端做術語提取**，同時是紅線違反。

## 修復（3 件）

| # | 層 | 修復 | 測試 |
|---|----|------|------|
| ① | `pdf2zh_next_adapter.build_command` | `if job.auto_extract and cfg.provider == "siliconflow"`——deepseek 不加 term 旗標（提取跳過，守敏感紅線） | `test_build_command_deepseek_auto_extract_no_term_flags` |
| ② | `parse_output` | log 無 MonoPDF/DualPDF 行 → `raise EngineError`（ghost COMPLETED 滅絕） | `test_translate_no_path_lines_raises_engine_error`＋`test_parse_output_no_path_lines_raises_engine_error` |
| ③ | `app._download_output` | 檔案不存在 → `ui.notify` 警告、不觸發下載（防 from_url fallback 送 HTML） | `test_download_guard.py` ×2 |
| ④ | `cli_adapter_base` 逾時 log | `error_chain` 也 redact（實測 log 曾有明文 SF key） | `test_timeout_log_error_chain_redacts_api_key` |

## 驗證

- 修復後真實引擎重跑（deepseek + auto_extract、無 term 旗標）：rc=0、無 401、
  產出 mono 424KB + dual 303KB、log 含 MonoPDF/DualPDF/Token 行。
- 修復後 `parse_output` 解析真實輸出：mono/dual 路徑 + tokens 5402/1576 ✓。
- **490 passed（+5）零回歸**；log 檔明文 key 行已清除（0 命中）。
