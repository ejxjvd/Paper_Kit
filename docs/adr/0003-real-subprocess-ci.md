# ADR 0003：真實子程序測試進 CI，全平台跑

- 狀態：已採納
- 日期：2026-08-19
- 來源：`Paper_Kit_journal/2026-08-19-Paper_Kit-工作紀錄.md`〈架構審查：13 項設計決策〉（Q3）
- 決策方式：`/improve-codebase-architecture` 產出候選 → `/grilling` 兩輪 → 使用者裁決

## 背景

繁中 Windows 上「整個產品不能用」等級的 bug 未被測試攔下。

## 決策

真實子程序測試進 CI，Windows／macOS 全平台跑，不標 slow。

## 替代方案與否決理由

只跑 mock 測試；或標 `slow` 後預設跳過——等於永遠不跑。成本僅數十毫秒，換到的是產品級故障的早期攔截。

## 後果

CI 於兩平台實際執行；故障一（cp950 解碼）由此類測試覆蓋。
