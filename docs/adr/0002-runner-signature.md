# ADR 0002：保留 `runner=` 注入簽名，既有測試零改動

- 狀態：已採納
- 日期：2026-08-19
- 來源：`Paper_Kit_journal/2026-08-19-Paper_Kit-工作紀錄.md`〈架構審查：13 項設計決策〉（Q2）
- 決策方式：`/improve-codebase-architecture` 產出候選 → `/grilling` 兩輪 → 使用者裁決

## 背景

約 30 處測試以 FakeRunner 注入假子程序。

## 決策

保留 `runner=` 簽名；測試不改。

## 替代方案與否決理由

改成依賴注入容器或 monkeypatch：那些測試測的是**命令組裝與輸出解析**，與執行機制無關，不該因重構變紅。

## 後果

重構期間測試維持綠燈，訊號未被稀釋。
