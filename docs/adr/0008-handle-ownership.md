# ADR 0008：核心回傳 handle，子程序所有權歸呼叫方

- 狀態：已採納
- 日期：2026-08-19
- 來源：`Paper_Kit_journal/2026-08-19-Paper_Kit-工作紀錄.md`〈架構審查：13 項設計決策〉（Q8）
- 決策方式：`/improve-codebase-architecture` 產出候選 → `/grilling` 兩輪 → 使用者裁決

## 背景

取消與逐行回調需要跨進核心。

## 決策

`spawn()` 為唯一啟動點並回傳 handle；等待方式由呼叫方選（stream／collect）。

## 替代方案與否決理由

回調式：會讓「誰持有子程序」變隱晦，而那正是死鎖 bug 的溫床。

## 後果

取消與逾時由呼叫方明確持有；死鎖類 bug 不再由所有權模糊產生。
