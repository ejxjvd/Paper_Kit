# ADR 0013：頁面級進度只先做引擎輸出留檔

- 狀態：已採納
- 日期：2026-08-19
- 來源：`Paper_Kit_journal/2026-08-19-Paper_Kit-工作紀錄.md`〈架構審查：13 項設計決策〉（Q13）
- 決策方式：`/improve-codebase-architecture` 產出候選 → `/grilling` 兩輪 → 使用者裁決

## 背景

進度條停在「排隊中」，需要更細的訊號。

## 決策

先只做引擎輸出留檔（`progress-debug`），**不**先寫頁面級進度解析。

## 替代方案與否決理由

直接從 stdout 猜頁數：沒有真實格式樣本，寫出來的正則是猜的；猜錯會靜默失效，比沒有更糟。

## 後果

留下真實樣本後再定案（後續見 ADR 相關紀錄：階段式進度 v0.2.2）。
