# ADR 0005：「拒絕」以回傳值表示，不以例外

- 狀態：已採納
- 日期：2026-08-19
- 來源：`Paper_Kit_journal/2026-08-19-Paper_Kit-工作紀錄.md`〈架構審查：13 項設計決策〉（Q5）
- 決策方式：`/improve-codebase-architecture` 產出候選 → `/grilling` 兩輪 → 使用者裁決

## 背景

選錯引擎、檔案不符條件等是預期中的正常結果。

## 決策

回傳值表達拒絕；例外只留給真正的異常。

## 替代方案與否決理由

丟例外：正常流程會走 traceback，日誌噪音與錯誤告警混在一起。

## 後果

呼叫方以分支處理拒絕；日誌中 traceback 只剩真異常。
